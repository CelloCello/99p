# 99乘法表練習程式

這是一個幫助小朋友練習九九乘法表的互動式網頁應用程式。採用可愛友善的界面設計，提供隨機出題、計時和成績統計功能。

url: https://cellocello.github.io/99p

## 功能特色

- 隨機生成九九乘法表題目
- 支援兩種練習模式：一般模式和進階模式
- 可自訂練習題目數量
- 自動計時，記錄完成時間
- 計算答題正確率
- 歷史記錄功能，可追蹤練習進度和表現趨勢
- 完全響應式設計，支援手機、平板和電腦
- 可愛友善的介面，適合小朋友使用

## 如何使用

1. 使用瀏覽器開啟 `index.html` 檔案
2. 在首頁選擇遊戲模式和題目數量
3. 點擊「開始練習」按鈕開始遊戲
4. 看到題目後在輸入框中輸入答案
5. 按下「確認」按鈕或按 Enter 鍵提交答案
6. 系統會立即顯示答案是否正確
7. 完成所有題目後，系統會顯示練習結果

## 練習模式

### 一般模式
簡單的乘法練習，給出兩個數字，讓使用者計算乘積。例如：2 × 3 = ?

### 進階模式
除了標準乘法題型外，還隨機出現需要求解乘數的題型，如：
- 2 × ? = 6（求解第二個數字）
- ? × 3 = 6（求解第一個數字）

這種模式能幫助小朋友更加靈活地理解乘法概念。

## 技術說明

這個應用程式使用純前端技術開發，包括：

- HTML5

不需要伺服器或特殊設定，直接在瀏覽器中開啟 HTML 檔案即可使用。
